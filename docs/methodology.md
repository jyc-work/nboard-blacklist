# 方法口径说明

## 1. 第 N 板定义

- **恰好第 N 板**（默认）：T 日及前 N-1 日连续涨停，且 T-N 日未涨停。
  - N=1：T 涨停、T-1 不涨停（首板）。
  - N=2：T、T-1 涨停，T-2 不涨停（二板）。
- **至少 N 板**（`--at-least`）：只要从 T 起向前连续涨停 >= N 天即可。

## 2. 涨停判定

优先用交易所涨停价：

```
is_limit_up = 收盘价 >= 涨停价 - 1e-3
```

- 聚宽：直接取 `high_limit` 字段；
- AKShare 等无该字段的数据源：用「前收 × (1+幅度)」计算涨停价（见下）。

### 涨停幅度（`rules.py`）

| 板块 | 幅度 | 备注 |
|---|---|---|
| 主板 | 10% | ST 为 5% |
| 创业板 | 20% | **2020-08-24 前为 10%** |
| 科创板 | 20% | |
| 北交所 | 30% | |

涨停价 = `round(前收 × (1 + 幅度), 2)`（A 股四舍五入到分）。

## 3. 复权与停牌

- **复权**：聚宽用 `fq='pre'`；AKShare 默认 `adjust=''`（不复权）以保证涨停判定精确。
  - 说明：涨停价基于原始价，故用不复权价计算最准；T+1 收益也基于不复权价，除权日会有少量噪声。
- **停牌**：
  - 前收：用停牌前最后成交价（避免复牌日涨停漏判）；
  - 次日停牌的样本直接剔除；
  - 聚宽用 `paused` 字段；AKShare 用缺行/成交量为 0 判断。

## 4. T+1 三档收益

均相对第 N 板当日收盘价 `entry_close`：

```
开盘 = T+1 open  / entry_close - 1
最高 = T+1 high  / entry_close - 1
收盘 = T+1 close / entry_close - 1
```

区间最后一天的板没有 T+1 数据，自动不计入。

## 5. 黑名单判定

默认「平均收盘收益率 < 0」。`--basis` 可切换：

| basis | 规则 |
|---|---|
| `close`（默认） | 平均收盘 < 0 |
| `open` | 平均开盘 < 0 |
| `both` | 平均开盘 < 0 且 平均收盘 < 0 |
| `any` | 平均开盘 < 0 或 平均收盘 < 0 |

## 6. 已知局限

- AKShare 计算涨停价对**极低价股**（分位四舍五入偏差大）可能有个别误判；
- **注册制新股上市前 5 日无涨跌幅限制**，未特殊处理；
- 未考虑滑点、一字板无法成交、复牌等交易细节；
- 样本数低于 `--min-sample`（默认 3）的票不进入结果。
